Building Classes

This post will cover “Building Classes”.

All objects are called classes, but we have to distinguish between sets and proper classes, which are two types of classes.

There is also a notation called membership notation, which is represented as follows.

If \(x\) and \(A\) are classes, and we want to say “x is an element of A”, “x belongs to A”, or “x is in A”, then we write

\[ x \in A \]

If \(x\) is not an element of \(A\), then we write

\[ x \notin A \]

Definition — Element

Let \(x\) be a class. If \(x\) is an element of some class \(A\), then \(x\) is called an element.

Lowercase letters represent elements, while uppercase letters may denote either elements or classes that are not elements.

In this framework, a set is a class that can be an element of another class, whereas a proper class cannot be an element of any class.

1. Equality and Inclusion

1.9 Definition — Equality of Classes

Let \(A\) and \(B\) be classes.

We define \(A=B\) to mean that every class that has \(A\) as an element also has \(B\) as an element, and vice versa.

In symbols,

\[ A=B \iff \forall X\, \left[ (A\in X\implies B\in X) \land (B\in X\implies A\in X) \right] \]

Equivalently,

\[ A=B \iff \forall X\,(A\in X\iff B\in X) \]

Axiom A1 — Axiom of Extent

Two classes are equal if and only if they have exactly the same elements.

\[ \boxed{ A=B \iff \forall x\, (x\in A\iff x\in B) } \]

This axiom is sometimes called the Axiom of Extent or Axiom of Extensionality.

1.10 Definition — Inclusion

Let \(A\) and \(B\) be classes.

We define \(A\subseteq B\) to mean that every element of \(A\) is also an element of \(B\).

In symbols,

\[ \boxed{ A\subseteq B \iff \forall x\, (x\in A\implies x\in B) } \]

If \(A\subseteq B\), then we say that \(A\) is a subclass of \(B\).

We define \(A\subsetneq B\) to mean that \(A\subseteq B\) and \(A\neq B\).

\[ A\subsetneq B \iff (A\subseteq B)\land(A\neq B) \]

In this case, we say that \(A\) is a strict subclass of \(B\).

If \(A\) is a subclass of \(B\) and \(A\) is a set, we call \(A\) a subset of \(B\).

1.11 Theorem — Properties of Equality and Inclusion

For all classes \(A\), \(B\), and \(C\), the following hold:

\[ \begin{aligned} \text{(i)}\quad & A=A\\ \text{(ii)}\quad & A=B\implies B=A\\ \text{(iii)}\quad & (A=B\land B=C)\implies A=C\\ \text{(iv)}\quad & (A\subseteq B\land B\subseteq A)\implies A=B\\ \text{(v)}\quad & (A\subseteq B\land B\subseteq C)\implies A\subseteq C \end{aligned} \]

Proof

(i) Reflexivity

The first statement is obvious because every element of class \(A\) belongs to \(A\).

For every element \(x\),

\[ x\in A\iff x\in A \]

Therefore, by Axiom A1,

\[ A=A \]

(ii) Symmetry

The second statement follows from Axiom A1.

If \(A=B\), then \(A\) and \(B\) have exactly the same elements.

Thus,

\[ \forall x\, (x\in B\iff x\in A) \]

Therefore,

\[ B=A \]

(iii) Transitivity of Equality

For the third statement, suppose that

\[ A=B \quad\text{and}\quad B=C \]

By Axiom A1,

\[ x\in A\iff x\in B \]

and

\[ x\in B\iff x\in C \]

for every element \(x\).

Combining these relations gives

\[ x\in A\iff x\in C \]

Thus, by Axiom A1,

\[ \boxed{A=C} \]

(iv) Antisymmetry of Inclusion

For the fourth statement, suppose that

\[ A\subseteq B \quad\text{and}\quad B\subseteq A \]

By the definition of inclusion,

\[ x\in A\implies x\in B \]

and

\[ x\in B\implies x\in A \]

Therefore,

\[ x\in A\iff x\in B \]

By Axiom A1,

\[ \boxed{A=B} \]

(v) Transitivity of Inclusion

For the last statement, suppose that

\[ A\subseteq B \quad\text{and}\quad B\subseteq C \]

If \(x\in A\), then \(x\in B\).

Since \(B\subseteq C\), we also have \(x\in C\).

Therefore,

\[ x\in A\implies x\in C \]

By the definition of inclusion,

\[ \boxed{A\subseteq C} \]

This completes the proof.

2. Class Construction

Axiom A2 — Axiom of Class Construction

Let \(P(x)\) be a statement about \(x\) expressed using the membership relation, logical connectives, quantifiers, brackets, and variables.

The axiom states that there exists a class \(C\) consisting of all elements \(x\) that satisfy \(P(x)\).

In symbols,

\[ \boxed{ C=\{x:P(x)\} } \]

Equivalently,

\[ \forall x\, (x\in C\iff P(x)) \]

Axiom A2 is called the Axiom of Class Construction.

From Axiom A2, we can infer that we can form a class of all elements that satisfy \(P(x)\), but this does not mean that we can form a class whose elements are all the classes satisfying \(P(X)\).

Why is this distinction important?

If we allow arbitrary classes to be collected as elements without restriction, logical paradoxes may arise.

For example, consider the class

\[ R=\{x:x\notin x\} \]

This is the class of all elements that do not belong to themselves.

Now, suppose that \(R\) itself is an element.

Then we can ask whether

\[ R\in R \]

holds.

By the definition of \(R\),

\[ R\in R \iff R\notin R \]

This is a contradiction.

Therefore, \(R\) cannot be an element of any class.

In this framework, \(R\) is a proper class, not a set.

The contradiction arises only if we incorrectly assume that this class can itself be treated as an element.

Thus, the distinction between elements and arbitrary classes is essential for avoiding Russell’s paradox.

1.12 Remark — Class Notation

The use of lowercase \(x\) in the expression

\[ C=\{x:P(x)\} \]

is not accidental.

Lowercase letters such as \(x\) and \(y\) represent elements, whereas uppercase letters such as \(A\) and \(B\) can represent arbitrary classes.

Therefore, the expression means that \(C\) is the class of all elements \(x\) satisfying \(P(x)\).

It does not assert that \(C\) contains every arbitrary class satisfying the property.

3. Operations on Classes

1.13 Definition — Union

Let \(A\) and \(B\) be classes.

The union of \(A\) and \(B\) is the class of all elements that belong to \(A\), \(B\), or both.

In symbols,

\[ \boxed{ A\cup B = \{x:x\in A\lor x\in B\} } \]

Thus,

\[ x\in A\cup B \iff (x\in A\lor x\in B) \]

1.14 Definition — Intersection

Let \(A\) and \(B\) be classes.

The intersection of \(A\) and \(B\) is the class of all elements that belong to both \(A\) and \(B\).

In symbols,

\[ \boxed{ A\cap B = \{x:x\in A\land x\in B\} } \]

Thus,

\[ x\in A\cap B \iff (x\in A\land x\in B) \]

1.15 Definition — Universal Class

The universal class \(\mathcal{U}\) is the class of all elements.

In symbols,

\[ \boxed{ \mathcal{U} = \{x:x=x\} } \]

By Theorem 1.11(i),

\[ x=x \]

holds for every element \(x\).

Therefore, every element belongs to the universal class.

\[ \forall x,\quad x\in\mathcal{U} \]

Its existence follows from the Axiom of Class Construction.

1.16 Definition — Empty Class

The empty class \(\varnothing\) is the class that has no elements.

In symbols,

\[ \boxed{ \varnothing = \{x:x\neq x\} } \]

By Theorem 1.11(i),

\[ x=x \]

for every element \(x\).

Therefore, no element can satisfy \(x\neq x\).

Hence,

\[ \forall x,\quad x\notin\varnothing \]

The existence of the empty class also follows from the Axiom of Class Construction.

1.17 Theorem — Empty and Universal Classes

For every class \(A\), the following hold:

\[ \boxed{ \begin{aligned} \text{(i)}\quad&\varnothing\subseteq A\\ \text{(ii)}\quad&A\subseteq\mathcal{U} \end{aligned} } \]

Proof

(i)

In order to prove that

\[ \varnothing\subseteq A \]

we must show that

\[ x\in\varnothing\implies x\in A \]

for every element \(x\).

However, the empty class has no elements.

Therefore, the antecedent \(x\in\varnothing\) is always false.

An implication with a false antecedent is true, so

\[ x\in\varnothing\implies x\in A \]

holds for every element \(x\).

Thus,

\[ \boxed{\varnothing\subseteq A} \]

(ii)

If \(x\in A\), then \(x\) is an element.

By the definition of the universal class, every element belongs to \(\mathcal{U}\).

Therefore,

\[ x\in A\implies x\in\mathcal{U} \]

Thus,

\[ \boxed{A\subseteq\mathcal{U}} \]

This completes the proof.

1.18 Definition — Disjoint Classes

If two classes have no elements in common, they are said to be disjoint.

In symbols,

\[ \boxed{ A\cap B=\varnothing } \]

Equivalently,

\[ \neg\exists x\, (x\in A\land x\in B) \]

1.19 Definition — Complement

The complement of a class \(A\) is the class of all elements that do not belong to \(A\).

In symbols,

\[ \boxed{ A'=\{x:x\notin A\} } \]

Thus,

\[ x\in A' \iff x\notin A \]

Since the complement is taken with respect to the universal class, we can also write

\[ A'=\mathcal{U}\setminus A \]
