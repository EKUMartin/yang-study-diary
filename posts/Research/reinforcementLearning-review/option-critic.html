Paper Review: The Option-Critic Architecture

Research
Reinforcement Learning
Paper Review
A review of the options framework, intra-option policy gradients, termination gradients, and the Option-Critic architecture.
공개

2026년 11월 1일

1. Introduction

This post reviews “The Option-Critic Architecture” by Pierre-Luc Bacon, Jean Harb, and Doina Precup.

In reinforcement learning, options are temporally extended actions that allow an agent to execute multiple primitive actions over time. They provide a framework for learning and planning with temporally extended behaviors.

Previous studies often focused on discovering subgoals and learning policies to achieve them. However, identifying useful subgoals can be difficult, and learning separate policies for those subgoals may require substantial data and computation.

This paper proposes an alternative approach: learning intra-option policies and termination functions directly through policy gradient methods, without requiring manually specified subgoals or additional rewards.

The key idea is to optimize the expected discounted return of the overall task rather than learning each option solely to accomplish a predefined subgoal.

2. The Options Framework

2.1 Definition of an Option

An option is represented by the following triple:

\[ \omega=(I_\omega,\pi_\omega,\beta_\omega) \]

where:

  • \(I_\omega\): Initiation set
  • \(\pi_\omega\): Intra-option policy
  • \(\beta_\omega\): Termination function

The initiation set specifies the states in which an option can be initiated.

\[ I_\omega\subseteq\mathcal{S} \]

The intra-option policy determines the probability of selecting a primitive action while executing an option.

\[ \pi_{\omega,\theta}(a\mid s) = P(a_t=a\mid s_t=s,\omega_t=\omega) \]

Here, \(\theta\) represents the parameters of the intra-option policy.

The termination function determines the probability that the current option terminates upon entering a state.

\[ \beta_{\omega,\vartheta}(s) = P(\text{terminate }\omega\mid s) \]

where

\[ 0\leq\beta_{\omega,\vartheta}(s)\leq1 \]

and \(\vartheta\) represents the parameters of the termination function.

Thus, an option specifies where it can start, how it selects primitive actions, and when it may terminate.

In the main derivations, the paper assumes that all options are available in every state:

\[ I_\omega=\mathcal{S}, \qquad \forall\omega\in\Omega \]

This assumption simplifies the mathematical analysis.

2.2 Call-and-Return Execution Model

The paper adopts the call-and-return option execution model.

An agent first selects an option according to a policy over options:

\[ \omega_t\sim\pi_\Omega(\cdot\mid s_t) \]

It then follows the selected intra-option policy:

\[ a_t\sim\pi_{\omega_t,\theta}(\cdot\mid s_t) \]

After the environment transitions to the next state, the termination function determines whether the option should end.

If the option continues, the agent follows the same option in the next state.

If the option terminates, the agent selects another option using \(\pi_\Omega\).

Therefore, the high-level policy does not necessarily select a new option at every primitive time step.

An option can persist across multiple primitive actions.

3. Value Functions for Options

The paper introduces three closely related value functions.

3.1 Option-Value Function

The option-value function is

\[ Q_\Omega(s,\omega) = \sum_a \pi_{\omega,\theta}(a\mid s) Q_U(s,\omega,a) \]

This represents the expected discounted return when option \(\omega\) is executed in state \(s\).

The function \(Q_U\) is the value of taking a primitive action \(a\) while executing option \(\omega\):

\[ Q_U(s,\omega,a) = r(s,a) + \gamma \sum_{s'} P(s'\mid s,a) U(\omega,s') \]

where:

  • \(r(s,a)\): Expected immediate reward
  • \(\gamma\): Discount factor
  • \(P(s'\mid s,a)\): State transition probability
  • \(U(\omega,s')\): Value upon arriving at the next state

The function \(U\) is defined as

\[ \begin{aligned} U(\omega,s') ={}& (1-\beta_{\omega,\vartheta}(s')) Q_\Omega(s',\omega)\\ &+ \beta_{\omega,\vartheta}(s') V_\Omega(s') \end{aligned} \]

This equation is important because it accounts for both possible outcomes after reaching the next state.

If the current option continues, its value is

\[ Q_\Omega(s',\omega) \]

If it terminates, the agent selects an option according to the policy over options, giving the value

\[ V_\Omega(s') = \sum_{\omega'} \pi_\Omega(\omega'\mid s') Q_\Omega(s',\omega') \]

The arrival value is therefore a probability-weighted combination of continuation and termination.

3.2 Interpretation of the Arrival Value

The distinction between \(Q_U\) and \(U\) is important.

\(Q_U(s,\omega,a)\) evaluates a primitive action in the context of the currently executing option.

In contrast, \(U(\omega,s')\) evaluates what happens after the agent reaches the next state and considers whether to continue or terminate the option.

The termination of an option does not necessarily imply the termination of the entire episode.

It only means that the current temporally extended action has ended and that another option may be selected.

4. Transition Probabilities over State-Option Pairs

To analyze option learning, the paper introduces an augmented state space consisting of state-option pairs:

\[ \mathcal{S}\times\Omega \]

The probability of transitioning from \((s_t,\omega_t)\) to \((s_{t+1},\omega_{t+1})\) is

\[ \begin{aligned} & P_\Omega(s_{t+1},\omega_{t+1}\mid s_t,\omega_t)\\ &=\sum_a \pi_{\omega_t,\theta}(a\mid s_t) P(s_{t+1}\mid s_t,a)\\ &\quad\times \Big[ (1-\beta_{\omega_t,\vartheta}(s_{t+1})) \mathbf{1}_{\{\omega_t=\omega_{t+1}\}}\\ &\qquad+ \beta_{\omega_t,\vartheta}(s_{t+1}) \pi_\Omega(\omega_{t+1}\mid s_{t+1}) \Big] \end{aligned} \]

The first term represents the probability of continuing the current option.

The second term represents the probability of terminating the option and selecting a new one.

The process is a time-homogeneous Markov chain when the environment dynamics and policies are stationary.

This means that its transition probabilities do not explicitly depend on the time index.

However, time homogeneity does not imply that the state distribution is stationary.

A stationary distribution exists and is unique only under additional conditions, such as appropriate irreducibility and recurrence assumptions.

5. Intra-Option Policy Gradient

The paper derives a policy gradient theorem for learning the parameters of intra-option policies.

The objective is to maximize the expected discounted return of the task:

\[ J(\theta,\vartheta) = \mathbb{E} \left[ \sum_{t=0}^{\infty} \gamma^t r_{t+1} \right] \]

Here, the expectation depends on the option policies and termination functions.

5.1 Gradient of the Option-Value Function

Recall that

\[ Q_\Omega(s,\omega) = \sum_a \pi_{\omega,\theta}(a\mid s) Q_U(s,\omega,a) \]

Differentiating with respect to \(\theta\) gives

\[ \begin{aligned} \nabla_\theta Q_\Omega(s,\omega) ={}& \sum_a \nabla_\theta\pi_{\omega,\theta}(a\mid s) Q_U(s,\omega,a)\\ &+ \sum_a \pi_{\omega,\theta}(a\mid s) \nabla_\theta Q_U(s,\omega,a) \end{aligned} \]

Substituting the Bellman equation for \(Q_U\) gives

\[ \begin{aligned} \nabla_\theta Q_\Omega(s,\omega) ={}& \sum_a \nabla_\theta\pi_{\omega,\theta}(a\mid s) Q_U(s,\omega,a)\\ &+ \gamma\sum_a\pi_{\omega,\theta}(a\mid s) \sum_{s'}P(s'\mid s,a) \nabla_\theta U(\omega,s') \end{aligned} \]

The first term represents the direct effect of changing the probability of primitive actions.

The second term represents the indirect effect on future returns.

5.2 Intra-Option Policy Gradient Theorem

The theorem states that

\[ \boxed{ \begin{aligned} \nabla_\theta Q_\Omega(s_0,\omega_0) ={}& \sum_{s,\omega} \mu_\Omega(s,\omega\mid s_0,\omega_0)\\ &\times \sum_a \nabla_\theta\pi_{\omega,\theta}(a\mid s) Q_U(s,\omega,a) \end{aligned} } \]

where

\[ \mu_\Omega(s,\omega\mid s_0,\omega_0) = \sum_{t=0}^{\infty} \gamma^t P(s_t=s,\omega_t=\omega\mid s_0,\omega_0) \]

is the discounted occupancy measure over state-option pairs.

It measures how frequently a state-option pair is visited along trajectories, weighted by the discount factor.

The gradient therefore combines the effect of a local policy change with its discounted frequency of occurrence.

5.3 Proof of the Intra-Option Policy Gradient Theorem

For this derivation, the policy over options and the termination functions are held fixed with respect to \(\theta\).

Step 1. Separate the local gradient

Define

\[ g_\theta(s,\omega) = \sum_a \nabla_\theta\pi_{\omega,\theta}(a\mid s) Q_U(s,\omega,a) \]

Then

\[ \begin{aligned} \nabla_\theta Q_\Omega(s,\omega) ={}&g_\theta(s,\omega)\\ &+\gamma\sum_a \pi_{\omega,\theta}(a\mid s) \sum_{s'}P(s'\mid s,a) \nabla_\theta U(\omega,s') \end{aligned} \]

Step 2. Differentiate the arrival value

Recall that

\[ U(\omega,s') = (1-\beta_\omega(s'))Q_\Omega(s',\omega) + \beta_\omega(s')V_\Omega(s') \]

Since the termination function is held fixed with respect to \(\theta\),

\[ \begin{aligned} \nabla_\theta U(\omega,s') ={}& (1-\beta_\omega(s')) \nabla_\theta Q_\Omega(s',\omega)\\ &+ \beta_\omega(s') \sum_{\omega'} \pi_\Omega(\omega'\mid s') \nabla_\theta Q_\Omega(s',\omega') \end{aligned} \]

This means that the gradient of the arrival value can be represented as a weighted combination of gradients of future option values.

Step 3. Express the recursion

Let

\[ G_\theta(s,\omega) = \nabla_\theta Q_\Omega(s,\omega) \]

and let \(T_\Omega\) denote the transition matrix over state-option pairs.

Substituting the previous equation gives

\[ G_\theta = g_\theta+\gamma T_\Omega G_\theta \]

Expanding the recursion,

\[ \begin{aligned} G_\theta &=g_\theta+\gamma T_\Omega G_\theta\\ &=g_\theta+\gamma T_\Omega g_\theta +\gamma^2T_\Omega^2G_\theta\\ &=\sum_{k=0}^{\infty} \gamma^k T_\Omega^k g_\theta \end{aligned} \]

The infinite expansion follows under the discounted setting and the usual boundedness conditions.

Step 4. Recover the occupancy measure

The term

\[ T_\Omega^k((s,\omega)\mid(s_0,\omega_0)) \]

represents the probability of reaching state-option pair \((s,\omega)\) after \(k\) transitions.

Therefore,

\[ \begin{aligned} G_\theta(s_0,\omega_0) ={}& \sum_{s,\omega} \left[ \sum_{k=0}^{\infty} \gamma^k P(s_k=s,\omega_k=\omega\mid s_0,\omega_0) \right]\\ &\times g_\theta(s,\omega) \end{aligned} \]

Recognizing the term in brackets as \(\mu_\Omega\) gives

\[ \boxed{ \nabla_\theta Q_\Omega(s_0,\omega_0) = \sum_{s,\omega} \mu_\Omega(s,\omega\mid s_0,\omega_0) \sum_a \nabla_\theta\pi_{\omega,\theta}(a\mid s) Q_U(s,\omega,a) } \]

This completes the derivation.

5.4 Interpretation

The theorem allows the agent to improve primitive-action policies while considering their contributions to the overall task.

Using the log-derivative identity,

\[ \nabla_\theta\pi_{\omega,\theta}(a\mid s) = \pi_{\omega,\theta}(a\mid s) \nabla_\theta\log\pi_{\omega,\theta}(a\mid s) \]

we obtain a sample-based gradient direction proportional to

\[ \nabla_\theta \log\pi_{\omega,\theta}(a\mid s) Q_U(s,\omega,a) \]

This leads to the intra-option policy update

\[ \boxed{ \theta \leftarrow \theta+ \alpha_\theta \nabla_\theta \log\pi_{\omega,\theta}(a\mid s) Q_U(s,\omega,a) } \]

Thus, the intra-option policy is updated to favor primitive actions that improve expected return.

6. Termination Gradient

The second major contribution is the termination gradient theorem.

Unlike the intra-option policy gradient, the termination gradient determines when an option should stop.

6.1 Gradient with Respect to Termination Parameters

The derivative of the option-value function with respect to \(\vartheta\) is

\[ \begin{aligned} \nabla_\vartheta Q_\Omega(s,\omega) ={}& \sum_a\pi_{\omega,\theta}(a\mid s) \sum_{s'}\gamma P(s'\mid s,a)\\ &\times\nabla_\vartheta U(\omega,s') \end{aligned} \]

The key quantity is therefore

\[ \nabla_\vartheta U(\omega,s') \]

because the termination decision is evaluated after the agent reaches the next state.

6.2 Advantage over Options

The advantage function over options is defined as

\[ \boxed{ A_\Omega(s,\omega) = Q_\Omega(s,\omega)-V_\Omega(s) } \]

This compares the value of continuing the current option with the expected value of selecting an option according to the high-level policy.

If

\[ A_\Omega(s,\omega)>0 \]

then the current option is more valuable than the high-level policy’s expected alternative.

If

\[ A_\Omega(s,\omega)<0 \]

then the current option is less valuable, making termination potentially beneficial.

6.3 Proof of the Termination Gradient

For this derivation, the intra-option policies and the policy over options are held fixed with respect to \(\vartheta\).

Step 1. Rewrite the arrival value

Start with

\[ U(\omega,s') = (1-\beta_{\omega,\vartheta}(s')) Q_\Omega(s',\omega) + \beta_{\omega,\vartheta}(s') V_\Omega(s') \]

Equivalently,

\[ U(\omega,s') = Q_\Omega(s',\omega) + \beta_{\omega,\vartheta}(s') \left[ V_\Omega(s')-Q_\Omega(s',\omega) \right] \]

Step 2. Differentiate with respect to termination parameters

Applying the product rule gives

\[ \begin{aligned} \nabla_\vartheta U(\omega,s') ={}& \nabla_\vartheta Q_\Omega(s',\omega)\\ &+ \nabla_\vartheta\beta_{\omega,\vartheta}(s') \left[ V_\Omega(s')-Q_\Omega(s',\omega) \right]\\ &+ \beta_{\omega,\vartheta}(s') \left[ \nabla_\vartheta V_\Omega(s') - \nabla_\vartheta Q_\Omega(s',\omega) \right] \end{aligned} \]

Combining terms,

\[ \begin{aligned} \nabla_\vartheta U(\omega,s') ={}& -\nabla_\vartheta\beta_{\omega,\vartheta}(s') A_\Omega(s',\omega)\\ &+ (1-\beta_{\omega,\vartheta}(s')) \nabla_\vartheta Q_\Omega(s',\omega)\\ &+ \beta_{\omega,\vartheta}(s') \nabla_\vartheta V_\Omega(s') \end{aligned} \]

The negative advantage term appears directly from differentiating the probability of termination.

This is the main mathematical reason for the negative sign in the termination gradient theorem.

Step 3. Express future gradients recursively

The remaining two terms depend on future returns.

Substituting the Bellman equations allows us to express the gradient as

\[ \begin{aligned} \nabla_\vartheta U(\omega,s') ={}& -\nabla_\vartheta\beta_{\omega,\vartheta}(s') A_\Omega(s',\omega)\\ &+ \gamma\sum_{\omega',s''} \widetilde{P}(s'',\omega'\mid s',\omega) \nabla_\vartheta U(\omega',s'') \end{aligned} \]

Here, \(\widetilde{P}\) is the transition kernel that first accounts for termination and option selection at \(s'\), and then transitions to the following state \(s''\).

It is a one-step-shifted representation of the augmented process.

Repeated substitution expands the gradient over all future state-option pairs.

Step 4. Introduce the shifted occupancy measure

Define

\[ \widetilde{\mu}_\Omega(s',\omega\mid s_1,\omega_0) = \sum_{t=0}^{\infty} \gamma^t P(s_{t+1}=s',\omega_t=\omega\mid s_1,\omega_0) \]

Unlike the intra-option policy gradient, which uses the pairs \((s_t,\omega_t)\), the termination gradient uses the next state together with the option that was active before the termination decision.

Expanding the recursion therefore gives

\[ \boxed{ \begin{aligned} \nabla_\vartheta U(\omega_0,s_1) ={}&- \sum_{s',\omega} \widetilde{\mu}_\Omega(s',\omega\mid s_1,\omega_0)\\ &\times \nabla_\vartheta\beta_{\omega,\vartheta}(s') A_\Omega(s',\omega) \end{aligned} } \]

This is the Termination Gradient Theorem in the arrival-state formulation.

6.4 Interpretation of the Termination Gradient

The termination gradient contains

\[ -\nabla_\vartheta\beta_{\omega,\vartheta}(s') A_\Omega(s',\omega) \]

Consider the following cases.

Case 1: Positive Advantage

\[ A_\Omega(s',\omega)>0 \]

The current option is relatively valuable. Gradient ascent generally encourages the termination probability to decrease.

Case 2: Negative Advantage

\[ A_\Omega(s',\omega)<0 \]

The current option is relatively less valuable. Gradient ascent generally encourages the termination probability to increase.

The corresponding parameter update is

\[ \boxed{ \vartheta \leftarrow \vartheta- \alpha_\vartheta \nabla_\vartheta\beta_{\omega,\vartheta}(s') A_\Omega(s',\omega) } \]

The key insight is that the agent learns when to terminate based on the relative value of the current option.

The algorithm does not require explicit termination labels or predefined subgoals.

7. The Option-Critic Architecture

The proposed architecture combines an actor with a critic, as in conventional actor-critic methods.

However, instead of learning only a policy over primitive actions, Option-Critic learns temporally extended behaviors.

The actor includes:

  • Intra-option policies
  • Termination functions
  • A policy over options

The critic estimates:

  • Action values within options, \(Q_U\)
  • Option advantages, \(A_\Omega\)

The critic evaluates behavior and supplies information for updating the actor.

8. Learning Algorithm

The paper combines intra-option value learning with gradient-based policy improvement.

8.1 One-Step Off-Policy Update Target

When the policy over options is greedy with respect to option values, the one-step update target is

\[ \begin{aligned} g_t^{(1)} ={}&r_{t+1}\\ &+\gamma\Big[ (1-\beta_{\omega_t,\vartheta}(s_{t+1})) Q_\Omega(s_{t+1},\omega_t)\\ &\qquad+ \beta_{\omega_t,\vartheta}(s_{t+1}) \max_{\bar{\omega}} Q_\Omega(s_{t+1},\bar{\omega}) \Big] \end{aligned} \]

The first component within the brackets represents continuing the current option.

The second component represents terminating it and selecting the most valuable option.

The TD error is

\[ \delta_t = g_t^{(1)} - Q_U(s_t,\omega_t,a_t) \]

For a terminal next state, the continuation value is set to zero.

The critic update is

\[ Q_U(s_t,\omega_t,a_t) \leftarrow Q_U(s_t,\omega_t,a_t) + \alpha\delta_t \]

8.2 Actor Updates

The intra-option policy is updated using

\[ \theta \leftarrow \theta+ \alpha_\theta \nabla_\theta \log\pi_{\omega_t,\theta}(a_t\mid s_t) Q_U(s_t,\omega_t,a_t) \]

The termination function is updated using

\[ \vartheta \leftarrow \vartheta- \alpha_\vartheta \nabla_\vartheta \beta_{\omega_t,\vartheta}(s_{t+1}) A_\Omega(s_{t+1},\omega_t) \]

Thus, the two updates serve different purposes.

The intra-option policy gradient improves which action to take.

The termination gradient improves when to stop the current option.

8.3 Simplified Pseudocode

The following is a simplified explanation of the learning procedure, rather than a direct reproduction of the paper’s algorithm.

Initialize option policies, termination functions,
the policy over options, and the critic.

For each episode:

    Observe the initial state.
    Select an initial option.

    Until the episode ends:

        1. Sample a primitive action
           from the current intra-option policy.

        2. Execute the action and observe
           the next state and reward.

        3. Calculate the TD target and TD error.

        4. Update the critic.

        5. Update the intra-option policy
           using the policy gradient.

        6. Update the termination function
           using the option advantage.

        7. If the current option terminates,
           choose an option using the
           policy over options.

        8. Continue from the next state.

The original paper presents a tabular implementation and also studies implementations with function approximation.

The authors use a two-timescale learning framework in which the critic is updated on a faster timescale than the policy and termination parameters.

9. Comparison with Actor-Critic

The main difference between conventional actor-critic and Option-Critic is the introduction of temporally extended actions.

Component Actor-Critic Option-Critic
Action selection Primitive-action policy Intra-option policies
Temporal abstraction Not explicitly modeled Explicit options
Termination learning Not applicable to ordinary primitive actions Learned termination functions
Critic State/action values Values and advantages involving options
Main objective Expected return Expected return

Both approaches optimize expected return.

However, Option-Critic introduces a hierarchy in which the agent can maintain a behavior over multiple time steps before selecting another option.

Therefore, it is not simply an actor-critic model that evaluates options instead of actions.

It learns both how to act within an option and when to switch between options.

10. Experimental Results

The paper evaluates the architecture in several environments.

10.1 Four-Rooms Domain

The first experiment considers navigation in a four-rooms environment.

After 1,000 episodes, the goal location changes.

The purpose is to examine whether learned options can help the agent adapt to a change in the environment.

The paper reports that Option-Critic adapts faster than the compared primitive actor-critic and SARSA(0) agents in this setting.

An interesting observation is that termination probabilities tend to become higher around doorways.

This suggests that useful temporal boundaries can emerge without explicitly providing doorway states as subgoals.

10.2 Pinball Domain

The Pinball environment has continuous state variables and requires controlling a ball through obstacles.

The experiments demonstrate that Option-Critic can learn temporally extended and specialized behaviors in this environment.

This is important because the framework is not restricted to small tabular state spaces.

10.3 Arcade Learning Environment

The paper also applies Option-Critic with deep neural network function approximation to Atari environments.

This demonstrates that the architecture can be combined with nonlinear function approximation.

However, the experimental results should not be interpreted as proving that Option-Critic is universally superior to other reinforcement learning algorithms.

11. Discussion and Limitations

The paper makes two important contributions.

First, it extends policy gradient methods to the options framework, allowing intra-option policies to be learned directly from the overall expected return.

Second, it derives a termination gradient that uses the option advantage to determine whether continuing an option is beneficial.

This enables learning temporally extended behaviors without requiring predefined subgoals.

Nevertheless, several considerations remain.

The number of options is still a design choice.

The framework also does not guarantee that all learned options will be distinct, interpretable, or equally useful.

Moreover, learning useful temporal abstractions depends on the task, the optimization process, and the chosen function approximators.

These limitations suggest that the quality and diversity of learned options should be evaluated rather than assumed.

12. Conclusion

The Option-Critic Architecture provides a framework for learning temporally extended actions using policy gradient methods.

The most important theoretical results are the Intra-Option Policy Gradient Theorem and the Termination Gradient Theorem.

The first determines how to improve primitive actions within an option.

The second determines when an option should terminate based on its advantage relative to alternative options.

Together, these results make it possible to learn the internal behavior and termination conditions of options while optimizing the expected discounted return of the overall task.
