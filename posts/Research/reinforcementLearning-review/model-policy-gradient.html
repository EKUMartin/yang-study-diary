Introduction

This post is about some of the most fundamental concepts in Reinforcement Learning: on-policy, off-policy, model-based, model-free learning, and policy gradients.

I will explain these concepts not only in words but also through equations and proofs.

1. On-Policy and Off-Policy

Let’s first compare on-policy and off-policy learning.

As you can infer from their names, the difference is related to the relationship between the behavior policy and the target policy.

The behavior policy determines how the agent selects actions, while the target policy is the policy being evaluated or improved.

This difference can be seen more clearly from the following equations.

1.1 On-Policy: SARSA

\[ \begin{aligned} Q(s_t,a_t)\leftarrow Q(s_t,a_t)+\alpha\Big[ &r_{t+1}\\ &+\gamma Q(s_{t+1},a_{t+1})\\ &-Q(s_t,a_t) \Big] \end{aligned} \]

1.2 Off-Policy: Q-Learning

\[ \begin{aligned} Q(s_t,a_t)\leftarrow Q(s_t,a_t)+\alpha\Big[ &r_{t+1}\\ &+\gamma\max_{a}Q(s_{t+1},a)\\ &-Q(s_t,a_t) \Big] \end{aligned} \]

The first equation is the on-policy SARSA update, and the second is the off-policy Q-learning update.

The main difference between these two equations is how they calculate the target for the future Q-value.

SARSA uses the next action actually selected by the current behavior policy.

In contrast, Q-learning uses the maximum estimated Q-value at the next state, regardless of which action the behavior policy actually chooses.

More technically, on-policy learning evaluates or improves the same policy that generates the agent’s behavior.

Therefore, its behavior policy and target policy are the same.

In contrast, off-policy learning can learn about a target policy using data generated by a different behavior policy.

For example, in Q-learning, the behavior policy may choose exploratory actions, while the update target uses the greedy action’s estimated value.

Thus, the behavior policy does not necessarily have to choose the same action as the target policy.

1.3 Advantages and Limitations

Then, what is the advantage of using on-policy learning?

When an agent explores the environment, on-policy methods can learn the value of the policy it actually follows, including the effects of exploration.

This can be useful when we want to evaluate and improve the agent’s actual behavior.

However, on-policy learning is not necessarily better when the state or action space is large.

Off-policy methods can also explore and may reuse experiences generated by other behavior policies, depending on the algorithm.

Therefore, neither method is universally better. Their suitability depends on the learning objective, exploration strategy, and available data.

2. Model-Based and Model-Free Reinforcement Learning

Next, we have model-based and model-free reinforcement learning.

A model describes or estimates how the environment changes when an agent takes an action.

It usually includes the state transition probabilities and the reward function.

\[ \mathcal{M}=(\mathcal{S},\mathcal{A},P,R,\gamma) \]

where:

  • \(\mathcal{S}\): State space
  • \(\mathcal{A}\): Action space
  • \(P(s'\mid s,a)\): State transition probability
  • \(R(s,a)\): Expected immediate reward
  • \(\gamma\): Discount factor

A model does not necessarily contain all information about the environment. It can also be an approximation learned from experience.

Model-based methods use a model for planning or decision-making.

Two typical examples are Value Iteration and Policy Iteration.

2.1 Value Iteration

One typical model-based method is Value Iteration.

The value function is updated using the Bellman optimality equation:

\[ \boxed{ V_{k+1}(s) = \max_{a\in\mathcal{A}} \left[ R(s,a) + \gamma \sum_{s'\in\mathcal{S}} P(s'\mid s,a)V_k(s') \right] } \]

After estimating the value function, we can obtain a greedy policy:

\[ \boxed{ \pi_{k+1}(s) \in \arg\max_{a\in\mathcal{A}} \left[ R(s,a) + \gamma \sum_{s'} P(s'\mid s,a)V_k(s') \right] } \]

The first equation calculates the value of a state by considering the immediate reward and the expected value of the next state.

It then selects the action that maximizes this value.

The updated value function is used in the next iteration.

This process is repeated until the value function converges to the optimal value function under the usual assumptions for a discounted MDP.

The optimal policy can then be obtained by selecting the action with the highest expected return.

Thus, Value Iteration primarily updates the value function using the Bellman optimality operator.

The policy is derived from the resulting value function.

This is model-based because the algorithm uses the transition probabilities and reward function to evaluate possible actions.

2.2 Policy Iteration

Another example is Policy Iteration, which is divided into Policy Evaluation and Policy Improvement.

Unlike Value Iteration, Policy Iteration explicitly alternates between evaluating a given policy and improving that policy.

Step 1. Policy Evaluation

First, Policy Evaluation can be written as

\[ \boxed{ \begin{aligned} V^{\pi_k}(s) ={}&R(s,\pi_k(s))\\ &+\gamma\sum_{s'} P(s'\mid s,\pi_k(s)) V^{\pi_k}(s') \end{aligned} } \]

This equation evaluates the value of each state under the given policy \(\pi_k\).

In Policy Evaluation, the policy is held fixed while its value function is calculated.

For a discounted MDP, this can be done by solving the Bellman expectation equation or by repeatedly applying its update until convergence.

Step 2. Policy Improvement

After evaluating the current policy, we calculate the Q-value of each possible action using the evaluated value function.

\[ Q^{\pi_k}(s,a) = R(s,a) + \gamma\sum_{s'} P(s'\mid s,a)V^{\pi_k}(s') \]

Then, we update the policy to select an action that maximizes the Q-value:

\[ \boxed{ \pi_{k+1}(s) \in \arg\max_{a\in\mathcal{A}} Q^{\pi_k}(s,a) } \]

The new policy is evaluated again, and the process is repeated.

Thus, Policy Iteration alternates between evaluating the current policy and improving it.

This is also model-based because the model is used to calculate the value of possible future states.

3. Model-Free Reinforcement Learning

For model-free reinforcement learning, we have Q-learning as an example.

Instead of explicitly using a transition model, Q-learning updates Q-values from observed interactions with the environment.

\[ \boxed{ \begin{aligned} Q(s_t,a_t)\leftarrow Q(s_t,a_t)+\alpha\Big[ &r_{t+1}\\ &+\gamma\max_a Q(s_{t+1},a)\\ &-Q(s_t,a_t) \Big] \end{aligned} } \]

The difference between model-based Value Iteration and model-free Q-learning can be seen in how they evaluate future states.

In Value Iteration, the future value is calculated using the transition probabilities:

\[ \sum_{s'}P(s'\mid s,a)V_k(s') \]

In Q-learning, the agent uses an observed transition and updates the estimated action value through a temporal-difference error:

\[ \boxed{ \delta_t = r_{t+1} + \gamma\max_aQ(s_{t+1},a) - Q(s_t,a_t) } \]

The update becomes

\[ Q(s_t,a_t) \leftarrow Q(s_t,a_t)+\alpha\delta_t \]

Thus, Q-learning does not require an explicit transition model.

It learns from the rewards and next states observed through interaction.

However, Q-learning is a value-based method, not a policy gradient method.

The policy is usually derived from the learned Q-values, for example through greedy or epsilon-greedy action selection.

4. Policy Gradient Theorem

Finally, we have the Policy Gradient Theorem.

Unlike Q-learning, which learns action values, policy gradient methods directly optimize the parameters of a policy.

Let the policy be parameterized by \(\theta\):

\[ \pi_\theta(a\mid s) \]

The objective is to maximize the expected discounted return:

\[ \boxed{ J(\theta) = \mathbb{E}_{\pi_\theta} \left[ \sum_{t=0}^{\infty} \gamma^t r_{t+1} \right] } \]

For this derivation, assume that the environment’s transition probabilities, reward function, and initial state distribution do not directly depend on \(\theta\).

We also assume a discounted infinite-horizon setting with \(0\leq\gamma<1\) and the regularity conditions needed to interchange differentiation and integration.

4.1 Discounted State-Visitation Measure

Let \(p_0(s_0)\) represent the initial state distribution.

The expected return can also be written as

\[ J(\theta) = \int_{\mathcal{S}} p_0(s_0)V^{\pi_\theta}(s_0)\,ds_0 \]

Define the discounted state-visitation measure as

\[ \boxed{ \rho^{\pi_\theta}(s) = \int_{\mathcal{S}} p_0(s_0) \sum_{t=0}^{\infty} \gamma^t p_{\pi_\theta}^{(t)}(s\mid s_0) \,ds_0 } \]

where

\[ p_{\pi_\theta}^{(t)}(s\mid s_0) \]

is the probability density of reaching state \(s\) after \(t\) steps from \(s_0\) while following the policy \(\pi_\theta\).

Using this measure, the expected return can be written as

\[ \boxed{ J(\theta) = \int_{\mathcal{S}} \rho^{\pi_\theta}(s) \int_{\mathcal{A}} \pi_\theta(a\mid s) R(s,a)\,da\,ds } \]

The discounted state-visitation measure represents the expected discounted frequency of visiting each state.

It is not necessarily a normalized probability distribution.

For an infinite-horizon discounted MDP, the normalized discounted state distribution can be defined as

\[ d^{\pi_\theta}(s) = (1-\gamma)\rho^{\pi_\theta}(s) \]

4.2 Policy Gradient Theorem

The Policy Gradient Theorem states that

\[ \boxed{ \begin{aligned} \nabla_\theta J(\theta) = \int_{\mathcal{S}} \rho^{\pi_\theta}(s) \int_{\mathcal{A}} &\nabla_\theta\pi_\theta(a\mid s)\\ &\times Q^{\pi_\theta}(s,a) \,da\,ds \end{aligned} } \]

This equation gives the gradient of the expected return with respect to the policy parameters.

The gradient indicates how the parameters should change locally to increase the expected return.

An important property is that we do not need to explicitly differentiate the discounted state-visitation measure in the final expression.

We will derive this equation step by step.

5. Proof of the Policy Gradient Theorem

Step 1. Express the objective using the value function

We begin with

\[ J(\theta) = \int_{\mathcal{S}} p_0(s_0)V^{\pi_\theta}(s_0)\,ds_0 \]

Since the value function can be written in terms of the action-value function,

\[ V^{\pi_\theta}(s_0) = \int_{\mathcal{A}} \pi_\theta(a_0\mid s_0) Q^{\pi_\theta}(s_0,a_0) \,da_0 \]

we obtain

\[ \begin{aligned} J(\theta) = \int_{\mathcal{S}} p_0(s_0) \int_{\mathcal{A}} &\pi_\theta(a_0\mid s_0)\\ &\times Q^{\pi_\theta}(s_0,a_0) \,da_0\,ds_0 \end{aligned} \]

Step 2. Differentiate with respect to theta

Taking the gradient gives

\[ \begin{aligned} \nabla_\theta J(\theta) = \int_{\mathcal{S}}p_0(s_0) \int_{\mathcal{A}} \nabla_\theta \Big[ &\pi_\theta(a_0\mid s_0)\\ &\times Q^{\pi_\theta}(s_0,a_0) \Big] \,da_0\,ds_0 \end{aligned} \]

Applying the product rule,

\[ \begin{aligned} \nabla_\theta J(\theta) ={}& \int_{\mathcal{S}}p_0(s_0) \int_{\mathcal{A}} \nabla_\theta\pi_\theta(a_0\mid s_0) Q^{\pi_\theta}(s_0,a_0) \,da_0\,ds_0\\ &+ \int_{\mathcal{S}}p_0(s_0) \int_{\mathcal{A}} \pi_\theta(a_0\mid s_0) \nabla_\theta Q^{\pi_\theta}(s_0,a_0) \,da_0\,ds_0 \end{aligned} \]

The first term represents the direct effect of changing the action probabilities.

The second term represents the effect of changing the policy on future returns.

Step 3. Expand the action-value function

The Bellman equation for the action-value function is

\[ Q^{\pi_\theta}(s,a) = R(s,a) + \gamma \int_{\mathcal{S}} P(s'\mid s,a) V^{\pi_\theta}(s') \,ds' \]

Differentiating with respect to \(\theta\) gives

\[ \begin{aligned} \nabla_\theta Q^{\pi_\theta}(s,a) ={}& \nabla_\theta R(s,a)\\ &+ \gamma\int_{\mathcal{S}} P(s'\mid s,a) \nabla_\theta V^{\pi_\theta}(s') \,ds' \end{aligned} \]

Since the immediate reward function is assumed to be independent of \(\theta\),

\[ \nabla_\theta R(s,a)=0 \]

Therefore,

\[ \boxed{ \nabla_\theta Q^{\pi_\theta}(s,a) = \gamma \int_{\mathcal{S}} P(s'\mid s,a) \nabla_\theta V^{\pi_\theta}(s') \,ds' } \]

This shows that the gradient of the action-value function depends on the gradients of future state values.

Step 4. Substitute into the value-function gradient

Recall that

\[ V^{\pi_\theta}(s) = \int_{\mathcal{A}} \pi_\theta(a\mid s) Q^{\pi_\theta}(s,a) \,da \]

Differentiating and using the previous result,

\[ \begin{aligned} \nabla_\theta V^{\pi_\theta}(s) ={}& \int_{\mathcal{A}} \nabla_\theta\pi_\theta(a\mid s) Q^{\pi_\theta}(s,a)\,da\\ &+ \gamma \int_{\mathcal{A}} \pi_\theta(a\mid s) \int_{\mathcal{S}} P(s'\mid s,a) \nabla_\theta V^{\pi_\theta}(s') \,ds'\,da \end{aligned} \]

Define

\[ g_\theta(s) = \int_{\mathcal{A}} \nabla_\theta\pi_\theta(a\mid s) Q^{\pi_\theta}(s,a)\,da \]

and the policy-induced transition kernel

\[ P_{\pi_\theta}(s'\mid s) = \int_{\mathcal{A}} \pi_\theta(a\mid s) P(s'\mid s,a)\,da \]

Then the gradient becomes

\[ \boxed{ \begin{aligned} \nabla_\theta V^{\pi_\theta}(s) ={}& g_\theta(s)\\ &+ \gamma\int_{\mathcal{S}} P_{\pi_\theta}(s'\mid s) \nabla_\theta V^{\pi_\theta}(s') \,ds' \end{aligned} } \]

This is a recursive expression because the gradient of the current state’s value depends on the gradients of future states’ values.

Step 5. Expand the recursion

Substituting the same recursive expression repeatedly gives

\[ \begin{aligned} \nabla_\theta V^{\pi_\theta}(s_0) ={}& g_\theta(s_0)\\ &+ \gamma \int_{\mathcal{S}} P_{\pi_\theta}(s_1\mid s_0) g_\theta(s_1)\,ds_1\\ &+ \gamma^2 \int_{\mathcal{S}} p_{\pi_\theta}^{(2)}(s_2\mid s_0) g_\theta(s_2)\,ds_2\\ &+\cdots \end{aligned} \]

Here,

\[ p_{\pi_\theta}^{(2)}(s_2\mid s_0) = \int_{\mathcal{S}} P_{\pi_\theta}(s_1\mid s_0) P_{\pi_\theta}(s_2\mid s_1)\,ds_1 \]

represents the two-step transition probability density under policy \(\pi_\theta\).

In general, the recursive expansion becomes

\[ \boxed{ \begin{aligned} \nabla_\theta V^{\pi_\theta}(s_0) = \sum_{t=0}^{\infty} \gamma^t \int_{\mathcal{S}} &p_{\pi_\theta}^{(t)}(s\mid s_0)\\ &\times g_\theta(s)\,ds \end{aligned} } \]

This means that the gradient at the initial state can be expressed as the discounted sum of local policy gradients over all future states.

Step 6. Substitute into the objective gradient

Recall that

\[ \nabla_\theta J(\theta) = \int_{\mathcal{S}} p_0(s_0) \nabla_\theta V^{\pi_\theta}(s_0) \,ds_0 \]

Substituting the recursive expansion,

\[ \begin{aligned} \nabla_\theta J(\theta) = \int_{\mathcal{S}} p_0(s_0) \sum_{t=0}^{\infty} \gamma^t \int_{\mathcal{S}} &p_{\pi_\theta}^{(t)}(s\mid s_0)\\ &\times g_\theta(s) \,ds\,ds_0 \end{aligned} \]

Rearranging the integrals and summation gives

\[ \begin{aligned} \nabla_\theta J(\theta) = \int_{\mathcal{S}} \Bigg[ \int_{\mathcal{S}} p_0(s_0) \sum_{t=0}^{\infty} \gamma^t p_{\pi_\theta}^{(t)}(s\mid s_0) \,ds_0 \Bigg] g_\theta(s)\,ds \end{aligned} \]

From the definition of the discounted state-visitation measure,

\[ \rho^{\pi_\theta}(s) = \int_{\mathcal{S}} p_0(s_0) \sum_{t=0}^{\infty} \gamma^t p_{\pi_\theta}^{(t)}(s\mid s_0) \,ds_0 \]

we obtain

\[ \nabla_\theta J(\theta) = \int_{\mathcal{S}} \rho^{\pi_\theta}(s) g_\theta(s)\,ds \]

Finally, substituting the definition of \(g_\theta(s)\),

\[ \boxed{ \begin{aligned} \nabla_\theta J(\theta) = \int_{\mathcal{S}} \rho^{\pi_\theta}(s) \int_{\mathcal{A}} &\nabla_\theta\pi_\theta(a\mid s)\\ &\times Q^{\pi_\theta}(s,a) \,da\,ds \end{aligned} } \]

This is the Policy Gradient Theorem.

Q.E.D.

6. Interpretation of the Policy Gradient

The theorem shows how the expected return changes when the policy parameters change.

Using the log-derivative identity,

\[ \nabla_\theta\pi_\theta(a\mid s) = \pi_\theta(a\mid s) \nabla_\theta\log\pi_\theta(a\mid s) \]

we can rewrite the policy gradient as

\[ \boxed{ \begin{aligned} \nabla_\theta J(\theta) = \int_{\mathcal{S}} \rho^{\pi_\theta}(s) \int_{\mathcal{A}} &\pi_\theta(a\mid s)\\ &\times\nabla_\theta\log\pi_\theta(a\mid s)\\ &\times Q^{\pi_\theta}(s,a) \,da\,ds \end{aligned} } \]

Therefore, the gradient depends on the probability of visiting a state, the likelihood of selecting an action, and the expected return from that action.

The parameters can then be updated through gradient ascent:

\[ \boxed{ \theta_{k+1} = \theta_k + \alpha\nabla_\theta J(\theta_k) } \]

This gives a direction for improving the policy’s expected return.

Unlike Q-learning, which updates an action-value function and derives a policy from it, policy gradient methods directly update the policy parameters.
